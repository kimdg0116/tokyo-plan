# Tokyo Plan — 도쿄 실행 플랜 앱

옵시디언의 [`🗺 도쿄 실행 플랜 2026-09`](../../../Desktop/Obsidian_Dongkyu) 노트를 폰에서 보는 PWA.
→ https://kimdg0116.github.io/tokyo-plan/ (배포 전)

```
index.html              앱 본체 (CSS·JS 전부 포함, 빌드 도구 없음)
data.json                지역·가게·사진 스폿·숙소·브랜드 지점·체크리스트
photos/                  구글 Places 사진 (가게 간판·매장) + 위키미디어 커먼즈 (센소지 등 랜드마크)
manifest.webmanifest     홈 화면 앱 설정
sw.js                    오프라인 캐시 (서비스 워커)
version.json             현재 버전 — 앱이 이 파일로 새 버전을 알아챈다
.nojekyll                GitHub Pages 가 `_` 로 시작하는 파일을 숨기지 않게
apple-touch-icon.png · icon-192.png · icon-512.png
```

## 기능

- **일정** 탭 — 날짜(전체·토·일·월·화) 고르면 그날 지역 카드. 카드 탭 → 가게 목록·사진 스폿·이동/시간
- **목록 / 지도 토글** — 일정 탭 안에서 바로 전환 (맛집 앱과 같은 방식). 지도엔 숙소(검정 핀)가 항상 뜬다
- **토·일 안 A/B 토글** — 스크램블 vs BIG JOHN, 이케부쿠로 밤 vs 밤 가와고에. 시간표·지역 목록·지도 전부 연동, 기기별 저장
- **가게 완료 체크** — 기기별 저장
- **다른 지점** — 몽벨·nanamica·RINKAN·BAPE 등 여러 지점 있는 브랜드는 가게 카드에서 펼쳐보면 다른 지점 주소·영업시간이 뜨고, 「지도에서 모아보기」로 그 브랜드 지점들만 지도에 모아 볼 수 있다
- **준비** 탭 — 출발 전 체크리스트 (옵시디언 `24 출발 전 준비 체크리스트.md` 와 같은 목록)
- **여유** 탭 — 일정엔 없지만 시간 남으면 갈 곳 (가게·사진 스폿·관광지)

## 데이터 갱신

가게·영업시간·사진·좌표는 구글 Places API(New)로 채운다:

```
python3 scripts/enrich.py
```

- API 키: `~/.config/tokyo-food/google_places.key` (도쿄 맛집 앱과 공유)
- 가게 이름이 흔한 영단어(예: 브랜드명)면 위키미디어 커먼즈 전문검색은 엉뚱한 문서 이미지를 집어올 수 있다 — **사진은 구글 Places로만** 받는다 (실제 장소 검색이라 정확도가 높다)
- 브랜드의 "다른 지점"은 `enrich.py` 의 `BRANDS` 딕셔너리에 손으로 등록한 것 — 새 브랜드/지점을 추가하려면 거기에 항목을 더한다

## 알아둘 것

- 체크·안 A/B 선택은 **기기별로 따로** 저장된다 (localStorage)
- 가게 정보는 여행 전 조사 시점 기준 — 가기 전 구글맵으로 한 번 더 확인
- [도쿄 맛집](https://github.com/kimdg0116/tokyo-food) 앱과는 별도 저장소다. 같은 여행이지만 맛집은 그쪽 앱에서 본다
